# Proposal

## Why

The completed five-question interview calls for more convincing industrial 3D art and a readable rest period between survival waves. The initial release has flat, simple geometry and advances waves immediately.

## What Changes

- Add layered metal architecture, surface detail, focused lighting, and articulated hero and hologram models.
- Make wave one approachable before the existing endless escalation.
- Clear threats, restore 20 health, and display `Wave X in Y secs...` for five seconds before the next wave. Pause must freeze this countdown.
- Preserve directional aiming and a single Echo power lasting ten seconds; verify replacement and expiry.
- Correct Spider wall-jump launch and animation resets.

## Capabilities

### New Capabilities

None.

### Modified Capabilities

- `survival-game`: Industrial presentation, opening pressure, explicit wave countdown, directional aiming, and mutually exclusive absorption.

## Impact

Pure simulation, Babylon Lite renderer, React HUD, focused tests, documentation, screenshots, and a new GitHub Actions release. No new dependencies or external assets.
